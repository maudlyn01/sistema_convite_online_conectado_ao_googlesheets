SISTEMA DE CONVITES ONLINE COM RSVP(Répondez s'il vous plaît/ Confirmação de Preseça)

FUNCIONALIDADES
✓ Link individual por convidado
✓ Nome personalizado
✓ Mesa personalizada
✓ Links Google Maps: Religiosa e Civil
✓ Confirmação SIM / NÃO
✓ Gravação das confirmações no Google Sheets
✓ Painel com estatísticas
✓ Lista e pesquisa de convidados

PUBLICAÇÃO
1. Publique todos os ficheiros no Netlify.
2. Crie uma Google Sheet chamada, por exemplo, "Bodas Lucas & Selfina".
3. Abra google-apps-script.js e siga os comentários para publicar o Apps Script.
4. Cole a URL /exec do Apps Script no campo "URL do Google Apps Script".
5. Cole a URL pública do Netlify no campo "URL pública do site".
6. Registe convidados e copie os links individuais.

NOTA IMPORTANTE
O painel administrativo guarda os convidados no navegador onde foi utilizado (localStorage).
As confirmações dos convidados ficam guardadas centralmente na Google Sheet configurada.
